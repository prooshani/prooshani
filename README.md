## Selected work

### [Discord Azure DevOps Bot](https://github.com/prooshani/Discord-Azure-bot)

A C#/.NET 8 integration project I developed to bring work-item and pull-request context into engineering conversations. Its implementation uses dependency injection, asynchronous REST requests, cancellation, caching, HTTP resilience and parser tests. It demonstrates integration design and failure handling around external APIs.

### [Reviso](https://github.com/prooshani/Azure-DevOps-Code-Review)

An independent Next.js/TypeScript code-review tool I develop around Azure DevOps, GitHub and local Git context, with cloud and local LLM providers. Repository style profiles and checks that reported snippets occur in supplied diffs help connect review output to the actual change. Further production hardening remains necessary.

### [Cachalot Lab](https://github.com/forera-ai/cachalot-lab)

A macOS application I develop through Forera to make local inference behavior easier to inspect. It combines React/TypeScript with Rust/Tauri for runtime health, cache telemetry, streaming chat and managed process supervision. Public release assets are available; broader experiment-comparison features remain planned.

### [Cachalot](https://github.com/forera-ai/cachalot)

An alpha-stage inference runtime I develop through Forera using Python, MLX and Metal on Apple Silicon. It explores running models whose expert weights exceed available memory through SSD streaming and bounded expert caching, exposed through OpenAI-compatible streaming endpoints. The engineering focus is memory, data movement, caching and runtime behavior.
